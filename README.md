# ASCII Art

A Python program that converts text into ASCII art using predefined banner fonts.

## Description

This project takes text as input and prints it as a graphical ASCII representation.

The project uses three provided banner files:

- `standard.txt`
- `shadow.txt`
- `thinkertoy.txt`

Each character in the banner files is represented by 8 lines of ASCII characters.

## Features

- Converts letters, numbers, spaces and special characters into ASCII art
- Supports different banner fonts
- Reads banner files and stores characters in Python dictionaries
- Prints the ASCII art line by line
- Supports repeated user input

## Requirements

- Python 3
- Only Python standard library packages are used

## Usage

Run the program with:

```bash
python3 ascii_art.py

```
